## 第二组：给运维 / IT

**1. 那台 Windows Server 具体是 2012 还是 2012 R2？**

> 这个决定技术方案：Server 2012 R2 可以用 Node.js，非 R2 的 2012 就得改用
> .NET Framework 重写后端。麻烦帮忙在服务器上运行 `winver` 确认一下。

**2. 服务器能否安装软件、开放一个内网端口（如 3000）？谁审批？**

**3. 有没有可能提供一台系统新一些的机器？**（Server 2016 及以上）
如果有，方案会简单不少。

**4. MAXHUB 大屏能装 Chrome 吗？型号和安卓版本是多少？**

> 大屏自带浏览器内核可能较旧，装新版 Chrome 更稳妥。

**5. 大屏走有线还是 Wi-Fi？能不能访问到部署服务器？**

> 车间环境 Wi-Fi 干扰大，建议优先接有线。

## 优先级说明

阻塞项只有两个，其余问题可以边做边确认：

| 问题 | 影响 |
|---|---|
| 数据从哪来（业务第 1、2 题） | 不确定就无法开发，且工作量可能差数倍 |
| 服务器是不是 R2（IT 第 1 题） | 决定后端用什么语言写 |

这两个有答案后，才能给出准确工期。
